# 个人主页

一个三屏的个人主页：**关于我** / **我的实习证明** / **一键去除图片背景**。
右上角还有一张北京的实时天气卡片。

前两屏和天气都是纯静态的（天气走公开接口，不需要 Key），
只有第三屏要接一个本地小后端来调用 Replicate 的抠图模型。

```
新项目-个人网页/
├── index.html      ← 网页本体（三屏 + 天气卡片都在这一个文件里）
├── server.py       ← 本地小后端，只干两件事：发静态文件 + 转发抠图请求
├── README.md       ← 你正在看的这个
└── 证件照.jpg      ← 原图（已经转成代码内嵌进 index.html 了，不删也不影响）
```

> 只想看**天气**和**前两屏**的话，直接双击 `index.html` 就行，不用启动任何服务。

---

## 一、先跑起来

### 1. 确认环境变量里有 API Key

Windows（**设置一次就够了**，之后永久生效）：

```bat
setx REPLICATE_API_TOKEN r8_你的token
```

macOS / Linux：

```bash
export REPLICATE_API_TOKEN=r8_你的token      # 想永久生效就写进 ~/.zshrc 或 ~/.bashrc
```

> ⚠️ **设完必须重开一个终端窗口**。`setx` 只对之后新开的程序生效，当前已经开着的终端读不到。
>
> 验证一下有没有生效：
> ```bat
> echo %REPLICATE_API_TOKEN%
> ```
> 打印出你的 token 就对了；打印 `%REPLICATE_API_TOKEN%` 说明没读到，重开终端再试。

### 2. 启动服务

在项目目录下：

```bash
python server.py
```

看到这样的输出就成了：

```
  个人主页 · 本地服务
  --------------------------------------------------
  地址      http://127.0.0.1:8000
  模型      lucataco/remove-bg
  Token     已读取（长度 40，前 3 位 r8_）
  --------------------------------------------------
  按 Ctrl+C 停止
```

如果显示 `Token [缺失]`，说明第 1 步的环境变量没读到 —— 重开终端再来。

### 3. 打开网页

浏览器访问 **http://127.0.0.1:8000**

> 直接双击 `index.html` 也能看，前两屏和右上角天气都完全正常，只有第三屏会提示「没连上本地后端」。
> 因为它必须有个后端帮忙保管 Key。

## 二、第三屏怎么用

1. 把图片**拖**进左边的框（也可以点击选择，或者直接 `Ctrl+V` 粘贴）
2. 点 **去除背景**
3. 等几秒，右边出现结果 —— 灰白格就是透明区域
4. 点 **下载结果** 保存 PNG（透明通道是保留的）

图片超过 2.5 MB 会自动压缩到 2000px 再上传，属于正常现象，面板上会标注。

## 三、右上角天气（北京）

页面右上角固定着一张小天气卡片，进页面自动加载，**每 10 分钟刷新一次**。

```
┌──────────────────────────┐
│ ☀  北京 晴                │   ← 城市 + 天气状况
│    26°  17~26°           │   ← 实时温度 + 今日最低~最高
└──────────────────────────┘
   （鼠标移上去，会多出一行：体感 27° · 湿度 55% · 风 5km/h）
```

**为什么它不需要 Key，也不需要后端：**

数据来自 [Open-Meteo](https://open-meteo.com/) 的公开接口 —— 免费、不注册、不用申请 Key，
并且响应头里带了 `access-control-allow-origin: *`，所以浏览器可以**直接请求**，不经过 `server.py`。
这也是为什么双击 `index.html`（`file://` 打开）时天气照样能显示。

请求长这样：

```
https://api.open-meteo.com/v1/forecast
  ?latitude=39.9042&longitude=116.4074
  &current=temperature_2m,relative_humidity_2m,apparent_temperature,is_day,weather_code,wind_speed_10m
  &daily=temperature_2m_max,temperature_2m_min
  &timezone=Asia/Shanghai&forecast_days=1
```

天气状况用的是 WMO 天气代码（`weather_code`），代码里已经全部翻译成中文，
并配了 8 个线条小图标（晴 / 月 / 多云 / 阴 / 雾 / 雨 / 雪 / 雷）。
图标颜色自动跟随主色 —— 改 `--main` 时它也会跟着变。

如果拉不到数据（断网、接口临时挂了），卡片会变成「天气没获取到 · 点这里重试」，**点一下卡片就重新拉**。

## 四、工作原理（为什么需要 server.py）

```
浏览器  ──①POST 图片──▶  server.py  ──②带上 Key──▶  Replicate API
        ◀──④返回图片───            ◀──③返回结果图──
```

**Key 只存在于 server.py 进程的环境变量里，永远不下发给浏览器。**
如果把 token 写进 `index.html`，任何人按 F12 看源码就能拿走，然后拿你的卡去跑模型。

### 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 返回 `{"token_configured": true/false}`，网页用它决定要不要弹警告 |
| POST | `/api/remove-bg` | 请求体 `{"image": "data:image/png;base64,..."}`，成功时直接返回图片二进制 |

### 换模型

改 `server.py` 顶部的这一行就行：

```python
MODEL = "lucataco/remove-bg"
```

版本号不用管 —— 代码会自己从 `GET /v1/models/{模型}` 里读 `latest_version.id`，不用手动填。

## 五、踩过的坑（都已在代码里修好，留个记录）

| 现象 | 原因 | 解法 |
|------|------|------|
| `找不到模型 lucataco/remove-bg`（404） | 这个 2023 年的老模型不支持 `POST /v1/models/{owner}/{name}/predictions` 这种新式接口 | 改用经典接口 `POST /v1/predictions` + `{"version": "..."}`，版本号运行时自动解析 |
| `读取模型信息失败（HTTP 403，error code 1010）` | Replicate 前面挂着 Cloudflare，会拦掉 Python `urllib` 的默认 User-Agent | 请求里固定带一个自己的 `User-Agent` |
| `Request was throttled`（429） | 账户余额不足 $5 时限制 6 次/分钟、突发 1 次 | 代码读了 `retry_after` 自动重试一次；连着猛点也会被限，等几秒就好 |
| 页面提示「没连上本地后端」 | 没启动 `server.py`，或者不是用 `http://127.0.0.1:8000` 打开的 | 启动服务，从 `127.0.0.1:8000` 访问 |
| 启动了却提示缺 Token | `setx` 之后没重开终端 | 关掉终端重新开一个 |
| 天气卡片显示「天气没获取到」 | 断网，或者 Open-Meteo 临时不可用 | 点一下卡片重试；不用管也行，不影响其他功能 |

> 端口被占用的话：`set PORT=8001` 再启动，然后访问 `http://127.0.0.1:8001`。

## 六、怎么改成你自己的

### 换颜色

`index.html` 里搜 `1. 配色`，那一坨 CSS 变量改一处，全站跟着变：

```css
:root{
  --main:      #ff7a5c;   /* 主色，现在是珊瑚橙 */
  --main-soft: #ffb199;   /* 主色浅版 */
  --main-tint: #fff1ec;   /* 主色最浅，做底色块 */
  --ink:       #3a2f2c;   /* 主要文字色 */
  --bg:        #fffaf7;   /* 页面背景色 */
  ...
}
```

### 换头像

搜 `←头像`，把 `src` 换成你的图片路径或网址：

```html
<img class="avatar" alt="头像" src="你的照片.jpg">
```

> 现在 `src` 里是一长串 `data:image/jpeg;base64,...`，那是证件照转成的代码，
> 图直接用这一串存着，所以整个网页可以单独拷走、发给别人也不丢图。想换就直接整段替换掉。

### 换文字

每一段文字上面都有中文注释，比如 `<!-- ←昵称：想换显示名就改这一行 -->`。
昵称出现在三处：浏览器标题栏 `<title>`、页面主标题 `<h1 class="name">`、页脚。换名字记得都改。

### 加一条实习记录

搜 `←一条时间线记录`，把整个 `<div class="tl-item">...</div>` 复制一份，改日期和内容即可。
（现在上面已经有 3 条：爬虫抓取 / 第一个个人网页 / 第一次 API 调用。）

### 换城市（右上角天气）

搜 `←天气城市`，改 `index.html` 里脚本的这三行就行：

```js
var WX_CITY = '北京';        // ←城市名（只是屏幕上显示的字）
var WX_LAT  = 39.9042;      // ←纬度
var WX_LON  = 116.4074;     // ←经度
```

> 经纬度随便填也行，Open-Meteo 会自己找最近的气象点。
> 不想记经纬度就去地图上右键点一下城市，或者搜「城市名 + 经纬度」，两个数字复制过来。

其它几个想调的地方：

| 想改什么 | 在哪 |
|----------|------|
| 刷新间隔（现在 10 分钟） | 脚本里的 `REFRESH_MS` |
| 卡片位置 | 样式里的 `.weather`，改 `top` / `right` |
| 让它只在第一屏显示、滚动就消失 | `.weather` 的 `position:fixed` 改成 `position:absolute` |
| 图标长什么样 | 脚本里的 `ICONS`，都是普通 SVG 路径 |

## 七、注意事项

- **不要在 `index.html` 里贴 token**，那样等于公开泄露。
- **不要在聊天记录、截图、GitHub 里贴 token**。万一贴过，去
  [replicate.com/account/api-tokens](https://replicate.com/account/api-tokens) 撤销重发一个。
- 每跑一次抠图都会**消耗你 Replicate 账户的额度**（这个模型很便宜，但注意别刷）。
- 服务只监听 `127.0.0.1`，同一局域网里的其他设备访问不到 —— 这是故意的，别改成 `0.0.0.0`，
  除非你清楚自己在做什么。
- 图片会经 Replicate 的服务器处理，涉及隐私的图自己想清楚再传。
